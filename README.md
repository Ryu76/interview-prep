# Briefing — 면접 준비 리서치

회사명과 지원 직무를 입력하면 다음을 한 화면에서 정리하는 웹앱입니다. 채용공고 URL 또는 공고 파일은 선택 입력입니다.

- 채용공고 기반 담당 업무·필수 요건·우대 사항
- 회사 연혁, 인재상/핵심가치, 사업 소개 관련 공개 검색 결과
- 직무 키워드 기반 예상 면접 질문
- 면접 후기 관련 공개 자료 링크
- 외부 LLM 키 없이 동작하는 텍스트 AI 모의면접과 적응형 꼬리질문
- 질문별 5개 항목 평가, 답변 근거 인용, 개선 구조 템플릿

## 텍스트 AI 모의면접

화면에서 회사, 직무, 신입/경력, 면접 유형(인성/직무/PT/임원), 난이도와
3~10개의 질문 수를 설정합니다. 채용공고와 자소서 텍스트는 선택 사항입니다.
답변에 역할·근거·수치가 모호하면 결정론적 엔진이 꼬리질문을 만들며, 세션,
질문, 답변과 평가는 `instance/interviews.sqlite3`에 저장됩니다. 개선 예시는 실제
경험을 만들어 내지 않고 사용자가 사실을 채우는 STAR 구조 템플릿만 제공합니다.

API는 다음과 같습니다.

- `POST /api/interviews` — 면접 시작 및 브라우저 전용 `accessToken` 발급
- `POST /api/interviews/<id>/answers` — 현재 `questionId`의 답변 및 평가/다음 질문
- `GET /api/interviews/<id>` — 진행 세션 조회
- `GET /api/interviews/<id>/result` — 완료 결과 조회

시작 이후 요청은 `X-Interview-Token` 헤더가 필요합니다. 토큰 원문은 시작 응답과 해당
브라우저의 `localStorage`에만 보관하고, SQLite에는 SHA-256 해시만 저장합니다. 페이지를
새로고침해도 진행 중 질문 또는 완료 결과를 복원하며, 동일 질문 답변 재전송은 차단합니다.

## 공고 입력 방식

- **필수**: 회사명, 지원 직무
- **선택**: 공개 채용공고 URL
- **선택**: 채용공고 파일 — PDF, PNG, JPG, JPEG, WEBP (최대 12MB)

텍스트 PDF는 직접 추출하고, 스캔된 PDF와 공고 이미지는 OCR로 읽습니다. 암호로 보호된 PDF는 지원하지 않으며, PDF는 앞의 12페이지만 분석합니다.

모든 외부 자료는 출처 링크를 함께 표시합니다. 페이지 접근 제한, robots 정책 또는 검색엔진 응답에 따라 일부 자료가 비어 있을 수 있으므로, 표시된 원문을 직접 확인하세요.
